# Agent instruction files

Parent: [technical/INDEX.md](INDEX.md) · Authority map: [CANONICAL_SOURCES.md](../CANONICAL_SOURCES.md) · Asset map: [ai-workflow/README.md](../ai-workflow/README.md)

This checkout adopted [synthet-code-framework](https://github.com/synthet/synthet-code-framework) with `--adopt` (Warp analog). Zed Agent, Cursor, Claude Code, and Gemini CLI do **not** share one file.

## Who reads what

Zed Agent loads the **first existing** file from `.rules` → `.cursorrules` → … → `AGENTS.md` → `CLAUDE.md` → `GEMINI.md`. With [`.rules`](../../.rules) present, Zed Agent never reads the other names.

| File | Role after adopt |
|------|------------------|
| [`.rules`](../../.rules) | Zed Agent always-on coding guidelines (GPUI, `./script/clippy`, PR hygiene). High-signal traps only. Do not dump framework scaffold here. |
| [`AGENTS.md`](../../AGENTS.md) | Cursor / Codex engineering guide (commands, MCP, backlog, `script/` vs `scripts/`) |
| [`CLAUDE.md`](../../CLAUDE.md) | Claude Code orientation (fork, crates, permissions) |
| [`GEMINI.md`](../../GEMINI.md) | Still a 6-byte `.rules` pointer so Gemini CLI gets coding guidelines |

Before adopt, `AGENTS.md` / `CLAUDE.md` / `GEMINI.md` were all `.rules` pointers. Naive `--adopt` would prepend a scaffold into those six bytes. The framework now **skips instruction-file pointers**; this repo then wrote full `AGENTS.md` and `CLAUDE.md` by hand.

## Canonical vs generated trees

Author under **`.claude/`** (+ **`.agent/`**). Regenerated by `python scripts/sync_assistant_trees.py`:

- `.cursor/{skills,commands,agents,rules}`
- `.agents/skills/`
- `.codex/agents/`

Do not hand-edit generated files. Install shared common-skills **globally** (`~/.agents/skills`). An in-repo install into `.agents/skills` is wiped on the next sync.

Domain skills live next to framework skills under `.claude/skills/`: `gpui-test`, `zed-cherry-pick`, `lint-creator`. Generic `rust-testing` is cargo/nextest; use `gpui-test` for scheduler/seed/`run_until_parked` failures.

## `script/` vs `scripts/`

- **`script/`** (singular) — product: `clippy`, `prettier`, `bootstrap`, `cherry-pick`, platform setup.
- **`scripts/`** (plural) — framework: `sync_assistant_trees.py`, frontmatter checks, inventory.

Prefer `./script/clippy` over bare `cargo clippy`. Commands: [guides/local-build.md](../guides/local-build.md), [`AGENTS.md`](../../AGENTS.md).

## What adopt did not touch

README, licenses, [`CONTRIBUTING.md`](../../CONTRIBUTING.md), product `script/`, `.github/workflows`, `.factory/`, `crates/agent_skills`, mdBook [`src/`](../src/). No framework CI. No `.agent/backlog/items.md`. No invented `specs/` tree.

Sibling framework repo: `../synthet-code-framework`. Re-adopt is copy-if-missing; do not use `--force` on this tree.

Backlog: [00-backlog-workflow.md](../project/00-backlog-workflow.md). Docs trees: [docs-map.md](docs-map.md).
